# Prespecified first sequence forecast experiment

Recorded before full training. This experiment keeps the 41 existing decision-time-safe features and the unchanged absolute NSW1 wholesale-price target. A sample at decision start `t` takes feature vectors for `t−355, t−350, …, t` minutes, shape `(72, 41)`, and predicts the price for the five-minute interval **starting at `t+60 minutes`**. The historical sequence covers six hours of five-minute feature rows; the prediction horizon is one hour; the prediction resolution remains one five-minute price. These are three different concepts. Individual feature rows already contain daily and weekly lag summaries, so six hours of rows is not the maximum raw-data lookback. Features at each historical row contain only information preceding that row under the project's optimistic AEMO publication assumption. The sequence therefore contains no current or future realised target price.

The chronological partitions and 41-feature CSV fingerprints remain frozen. The 12 train-origin rows omitted because their labels cross into validation are rebuilt **only as historical input context** from the checksum-verified December 2024 processed file, using the existing feature formula. They never become training labels. This permits first January tuning origins to look back across the partition. Development-week and June/July boundary rows are likewise available only as context when eligible, never as training or scored targets. Sequences are views into one shared chronological feature matrix, constructed on demand; there is no materialised `(number of samples, 72, 41)` tensor. The first 71 training origins lack complete prior feature-row history and are excluded. All 50,100 tuning and 44,040 reused July–November evaluation origins retain full context and match the earlier comparisons. StandardScaler mean and scale are fitted on the 208,800 original training feature rows alone and frozen for all three networks.

## Architectures and mathematics

Each network reads a batch tensor `(B, 72, 41)` and emits `(B,)` unrestricted linear prices in AUD/kWh; negative predictions are possible. Loss is mean absolute error `mean(|prediction−target|)`, with no price clipping or weighting. AdamW updates parameters with adaptive first/second gradient moments and decoupled weight decay. The fixed seed is 42.

| Architecture | State update and dimensions | Fixed capacity and main tradeoff |
| --- | --- | --- |
| LSTM | For input `x_t` and prior hidden `h`, cell `c`, input gate `i=σ(W_i[x,h]+b_i)`, forget gate `f=σ(W_f[x,h]+b_f)`, candidate `g=tanh(W_g[x,h]+b_g)`, new cell `c'=f⊙c+i⊙g`, output gate `o=σ(W_o[x,h]+b_o)`, hidden `h'=o⊙tanh(c')`. Last hidden `(B,32)` goes to `Linear(32,1)`. | One layer, hidden width 32. Gates can retain useful history and control forgetting; recurrent steps limit parallelism. **9,633 trainable parameters.** |
| GRU | Reset `r=σ(W_r[x,h])` controls prior hidden contribution to candidate `n=tanh(W_nx+b_n+r⊙(U_nh+c_n))`; update `z=σ(W_z[x,h])` mixes candidate and old state, `h'=(1−z)⊙n+z⊙h`. Last hidden `(B,40)` goes to `Linear(40,1)`. | One layer, hidden width 40. Fewer gates than LSTM; similar capacity with no separate cell state. **10,001 trainable parameters.** |
| TCN | Seven residual causal Conv1d blocks map `(B,41,72)` to `(B,24,72)`. Each left-pads only past values, uses kernel size 2 and dilations `1,2,4,8,16,32,64`, ReLU and a residual skip; the first skip projects 41 to 24 channels. Last time step `(B,24)` goes to `Linear(24,1)`. | Receptive field `1+(2−1)Σd = 128` feature rows, covering all 72. Temporal convolutions parallelise across time, but the fixed 72-row window limits available history. **10,081 trainable parameters.** |

## Fixed training plan and resource choice

- Existing machine: 16 logical CPU cores, 13.81 GiB physical RAM (2.95 GiB free at inspection), NVIDIA RTX 3050 laptop GPU with 6 GiB VRAM. PyTorch 2.15.0 installs and imports in the existing Python 3.14.7 environment as `2.15.0+cpu`; CUDA is unavailable in that wheel. Train on CPU with four PyTorch threads, zero data-loader workers and moderate batches. Report actual process CPU time and peak memory where available; GPU usage is zero for this run.
- Same AdamW learning rate `0.001`, weight decay `0.0001`, batch size `512`, gradient-norm clip `1.0`, max `8` epochs and patience `2` epochs without a tuning-MAE improvement of at least `0.0001` AUD/kWh. Keep the best tuning epoch. Train order is reproducibly shuffled within training only; tuning/evaluation are chronological. This is one fixed configuration per architecture, not a sweep.
- Benchmark an initial short training pass before launching full runs. If full epochs prove impractical, report measured runtime rather than silently reducing the dataset, changing model capacity or claiming complete results.
- July–November remains **reused development evaluation**, not an independent test. Compare against all 14 existing forecasts on identical rows. Do not inspect December 2025–February 2026.

Sequence models receive additional historical feature vectors that single-row tabular models do not. Any accuracy difference therefore mixes architecture with input-information differences. No inference about downstream trading value follows from one-hour price errors alone.
